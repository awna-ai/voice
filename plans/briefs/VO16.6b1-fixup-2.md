## Steps (test first)

1. **`Radio::hello` in `builder/api/src/radio.rs`.** Today a `hello` answer whose `protocol.major` isn't
   `PROTOCOL_MAJOR` gets `text::TOO_OLD` ("older than this Voice"), but a major-2 daemon would be newer, and Radio's
   install never replaces a newer copy, so that sentence would be false. Split the check:
   - `protocol.major != PROTOCOL_MAJOR` returns `Err(Error::Invalid(text::OTHER_MAJOR.into()))` (the constant already
     exists and is what an `unsupported_version` answer gets).
   - `protocol.minor < PROTOCOL_MINOR` or a missing link op keeps `text::TOO_OLD`.
   - Keep the doc comment true: `/// Radio's version, refusing another major, one older than this Voice, or one
     missing a link op.`
   **Red first** in `builder/api/src/radio/tests.rs`: take the `other_major` case out of
   `hello_refuses_a_radio_that_cannot_link` (that test keeps `old` and `missing_op`) and add
   `hello_refuses_another_major_with_its_own_sentence`, which answers the `link_hello()` with major 2 and asserts
   `text::OTHER_MAJOR` and the one `hello` request, in the style of its neighbours. It fails before the code change.
2. **`builder/cli/tests/radio.rs` `radio_message_is_refused_printing_and_writing_nothing`:** replace
   `assert!(!output.status.success());` with `assert_eq!(output.status.code(), Some(2));` (`.ai/SECURITY.md` promises
   exit 2, clap's usage error).
3. Run `cargo test --locked -p voice-api --lib radio:: -- --test-threads=2`,
   `cargo test --locked -p voice-cli --test radio -- --test-threads=2` (socket tests may be refused by your sandbox;
   say so), `cargo fmt --check`, `cargo clippy --all-targets --locked -- -D warnings`.
