How to install Voice on your Mac

Voice works with Claude Code. If you don't have it yet, the app tells you how to get it;
then you sign in to Claude from the app's Connect Claude step.

1. Double-click the zip file you were sent. A folder called "Voice" appears next to it.
2. Open Terminal: press Command and Space, type Terminal, then press Return.
3. Check that this is the copy you were sent. Type shasum -a 256 and a space, drag the zip file
   into the Terminal window, then press Return. A long code appears. It must match the code you
   were sent separately, letter for letter. If it doesn't, stop and ask for a new copy.
4. Type bash and a space. Drag the file install.sh from the "Voice" folder into the
   Terminal window, then press Return.
5. Voice opens. Next time, you'll find it in the Applications folder inside your home
   folder (in the Finder, choose Go, then Home).

This copy isn't signed by Apple yet, so the installer tells your Mac it is safe to open. It asks
for no password. It also sets up Radio, a small program that comes with Voice and links your
computers, so one assistant can work on all of them. Radio runs in the background from when you
sign in to your Mac, and Voice checks on it each time you open it. Voice works without it.

To remove the app, first turn Radio off for it: in Terminal, type
~/Applications/Voice.app/Contents/MacOS/radio uninstall --app voice
then press Return. Then drag the app from that Applications folder to the Trash. Your assistant
stays. To delete what the app made, use Forget in the app first.
